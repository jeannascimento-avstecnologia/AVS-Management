### Legenda Status

- **Go** — path confirmado (doc oficial e/ou script/client no repo).
- **Go (doc) / Unknown (live)** — documentado; **sem** POST live neste O2.0 (sem `.tiflux_token` / `.vhsys_credentials` em `docs/hub/`).
- **No-Go** — ausente / 404 / só leitura onde escrita é necessária.
- **Go parcial** — caminho indireto documentado; precisa smoke live.
