Nota sobre TiFlux “faturar”

  • API v2: leitura de contratos + histórico OK · pending/faturar = 404
  • Fila e fechamento ficam no Management; TiFlux recebe o ticket de cobrança
  • Opcional depois: RPA ou endpoint futuro para espelhar faturamento no TiFlux

Roadmap de entrega

Fase 0 — Base (já existe)

  • avs-management: cadastro/consulta/inativar CNPJ → TiFlux + VHSYS
  • API TiFlux JWT validada (clients, contracts, tickets, desks, billing history)

Fase 1 — Orçamento no Management (O1)

  • UI implantação + mensalidade, templates, desconto, modal cliente
  • Persistência quotes · PDF · temperatura lead

Fase 2 — n8n comercial (O2–O3)

  • OS VHSYS + ticket TiFlux + anexo + kanban + follow-up e-mail
  • Gerar contrato a partir do orçamento aprovado

Fase 3 — Faturamento hub (F1A)

  • Fila no Management + aprovação + n8n VHSYS + ticket cobrança
  • Branch retenção prefeitura assistida

Fase 4 — Evoluções

  • Grafana → quantidades · substituir Excel buffer
  • Endpoint TiFlux pending (se/quando existir) ou RPA pontual
