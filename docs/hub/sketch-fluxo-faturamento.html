Exceção

Regras de negócio (AS-IS)

  • Data-base nos faturamentos pendentes deve ser futura, senão o TiFlux não lista.
  • Sempre marcar contratos + valores avulsos (tickets).
  • Linhas zeradas → faturamento parcial.
  • Excel existe para acumular alterações e não antecipar a próxima mensalidade.
  • Cancelar contrato com data de ontem para preservar histórico.
  • Ticket exige relatório + NF + boleto e comunicação interna.
  • Com retenção: NF na prefeitura; VHSYS recebe valor líquido.
